# Quaternius assets in Eteria 6

Eteria 6 uses Quaternius humanoid assets without committing the downloaded GLB files to this repository.

## Runtime layout

```text
frontend/public/assets/quaternius/runtime/
├─ characters/
│  ├─ male_ranger.glb
│  ├─ male_peasant.glb
│  ├─ male_head.glb
│  ├─ hair_simpleparted.glb
│  ├─ hair_buzzed.glb
│  ├─ female_ranger.glb
│  ├─ female_head.glb
│  └─ hair_long.glb
└─ animations/
   ├─ genesara_idle.glb
   ├─ UAL1_Standard.glb
   └─ UAL2_Standard.glb
```

The directory is generated by `scripts/fetch-quaternius-assets.mjs` during `npm run dev` and `npm run build`.

## Source packs

- Quaternius — Universal Base Characters:
  https://quaternius.itch.io/universal-base-characters
- Quaternius — Modular Character Outfits - Fantasy:
  https://quaternius.itch.io/modular-character-outfits-fantasy
- Quaternius — Universal Animation Library:
  https://quaternius.itch.io/universal-animation-library
- Quaternius — Universal Animation Library 2:
  https://quaternius.itch.io/universal-animation-library-2

The current Standard pack pages identify the free assets as CC0. Quaternius also publishes a site-wide asset license, so licensing should be rechecked before a commercial release if the upstream terms change.

## Build sources and integrity

Character components are fetched from the optimized Quaternius-derived files in:
- `Genesara/genesara-web`
- pinned commit: `90c166baa14682eedf1358c6c0a6e40e91765495`

Animation sources are pinned separately:
- compatible idle pose: `Genesara/genesara-web` at `90c166baa14682eedf1358c6c0a6e40e91765495`
- UAL1 locomotion: `DyingStar-game/DyingStar` at `8bf981c9a1ba6e19fcbfe48c7ee2ac1edeedec6b`
- UAL2 combat: `agentkaerf/FreeModels` at `db3df04d1e4714298a09510b26fb6de6645138a2`

Every downloaded file is checked against its Git blob SHA before it is written to the build directory. This prevents a moving upstream branch from silently changing the assets used by Eteria.

## Runtime integration

`src/quaterniusAssets.js` owns:

- modular humanoid assembly (outfit + head + hair);
- synchronized animation mixers for every modular layer;
- idle / walk / run / dodge and combat animation selection;
- right- and left-hand weapon sockets;
- dual dagger support;
- equipment-driven hero presets: Guardián, Explorador and Espadachín del Éter;
- humanoid Liora and Eldren NPC visuals;
- fallback-safe loading;
- runtime validation of leg motion; if an external walk/run clip fails to bind, Eteria switches to a bone-driven gait instead of allowing the hero to slide in T-pose.

Default hero order:

1. Quaternius Eteria 6
2. KayKit Eteria 5
3. procedural Eteria hero

Testing overrides:
- `?hero=kaykit`
- `?hero=procedural`
- `?rig=1` keeps the older experimental generated rig.
